JavaScript (JS Vanilla)

Que es JavaScript?

JavaScript es un lenguaje de programacion interpretado que se ejecuta en el navegador. Permite crear comportamiento interactivo en las páginas web: animaciones, validación de formularios, juegos, etc.

HTML vs CSS vs JS

  • HTML: Estructura (el esqueleto de la pagina)
  • CSS: Estilo (la ropa y apariencia)
  • JS: Comportamiento (los musculos y movimiento)

Conceptos basicos

  • Variables: Guardan datos (let, const)
  • Funciones: Bloques de codigo reutilizables
  • Eventos: Acciones del usuario (click, hover, keypress)

Ejemplo practico

// Variable
let puntos = 0;

// Funcion
function sumarPunto() {
  puntos = puntos + 1;
  document.getElementById("contador").innerText = "Puntos: " + puntos;
}

// Evento
document.getElementById("btn").addEventListener("click", sumarPunto);
Puntos: 0

jQuery

Que es jQuery?

jQuery es una libreria de JavaScript creada en 2006 por John Resig. Su objetivo: simplificar el manejo del DOM, eventos y animaciones con menos codigo.

Sintaxis basica

Todo empieza con $ (el simbolo de jQuery):

$(selector).accion();

// Ejemplo: ocultar un elemento
$("#miElemento").hide();

// Ejemplo: al hacer click
$("button").click(function(){
  alert("Click!");
});

Ventajas vs Desventajas

✅ Ventajas: Codigo mas corto, compatible con navegadores antiguos, muchas animaciones listas.

❌ Desventajas: JS moderno (ES6+) ya hace casi todo, añade peso al sitio, menos usado en proyectos nuevos.

JSON

Que es JSON?

JavaScript Object Notation formato ligero de intercambio de datos. Es texto plano, fácil de leer para humanos y máquinas. Es el estándar para APIs web.

Estructura basica

  • Pares clave-valor: "nombre": "valor"
  • Objetos: entre llaves { }
  • Arreglos: entre corchetes [ ]

Objeto JS vs Cadena JSON

Objeto JavaScript:

let jugador = {
  nombre: "Link",
  vida: 100,
  items: ["espada", "escudo"]
};

Cadena JSON:

'{"nombre":"Link","vida":100,"items":["espada","escudo"]}'

En JSON las claves siempre van entre comillas dobles.

Conversion en JS

// Objeto  JSON (enviar al servidor)
let texto = JSON.stringify(jugador);

// JSON  Objeto (recibir del servidor)
let datos = JSON.parse(texto);

Para que se usa?

Cuando tu web se comunica con un servidor (API), los datos viajan en JSON. Ejemplo: obtener el ranking de jugadores, cargar inventario, guardar partida.

Web Hosting y Dominios

Que es Web Hosting?

Es un servicio que almacena los archivos de tu sitio web en un servidor conectado a internet 24/7, para que cualquiera pueda visitarlo.

Tipos de Hosting

  • Compartido: Varios sitios en un mismo servidor. Barato, limitado.
  • VPS: Servidor virtual privado. Mas recursos, mas caro.
  • En la nube (Cloud): Red de servidores escalable. Ej: AWS, Vercel.

Como funciona Vercel?

Vercel es una plataforma para sitios estaticos y aplicaciones frontend. Se conecta a tu repositorio de GitHub y despliega automaticamente cada vez que haces push. Incluye CDN global para carga rapida.

Dominios

Dominio: Nombre legible para acceder a un sitio (ej: nexusgames.com).

TLD: La extension (.com, .net, .org, .io).

Subdominio: Parte antes del dominio principal (ej: tienda.nexusgames.com).

Propagacion DNS (flujo)

Usuario escribe: nexusgames.com
        ↓
Servidor DNS traduce → IP del servidor (ej: 76.76.21.21)
        ↓
Navegador conecta al servidor
        ↓
Servidor entrega los archivos HTML/CSS/JS
        ↓
Sitio visible!

La propagacion DNS puede tardar hasta 48 horas mundialmente.
