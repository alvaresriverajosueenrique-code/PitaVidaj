JavaScript

El lenguaje que agrega comportamiento e interactividad a una página web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento a las páginas web.

Permite responder a las acciones realizadas por los usuarios, modificar elementos de una página y crear aplicaciones web interactivas.

HTML, CSS y JavaScript

HTML: define la estructura de la página.

CSS: define el diseño, colores y estilos.

JavaScript: agrega comportamiento e interacción.

Conceptos básicos

Variables: almacenan información.

Funciones: contienen instrucciones que pueden ejecutarse cuando son llamadas.

Eventos: permiten responder a acciones como hacer clic, mover el mouse o cargar una página.

Ejemplo práctico

El siguiente código cambia el texto de un elemento cuando el usuario hace clic en un botón. 

const boton = document.getElementById("boton");

boton.addEventListener("click", function() {

    document.getElementById("mensaje").textContent =
        "Pitajalla es deliciosa!";

});
