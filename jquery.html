jQuery

Una libreria de JavaScript para facilitar el desarrollo web.

Que es jQuery?

jQuery es una libreria de JavaScript creada para simplificar tareas comunes del desarrollo web.

Facilita la manipulacion de elementos HTML, eventos, animaciones y otras tareas.

Sintaxis basica

Una de las caracteristicas principales de jQuery es el uso del simbolo $. 

$("#mensaje").hide();

$("#boton").click(function() {

    $("#mensaje").show();

});

Ventajas

✔ Sintaxis sencilla.

✔ Facilita el manejo de eventos.

✔ Permite crear animaciones facilmente.

✔ Simplifico problemas de compatibilidad entre navegadores.

Desventajas

Actualmente JavaScript moderno incluye muchas funciones que anteriormente requerian jQuery.

Por esta razon, muchos proyectos actuales utilizan JavaScript moderno sin necesidad de esta libreria.

Efectos de jQuery

$("#imagen").fadeIn();

$("#menu").slideToggle();

fadeIn() muestra un elemento gradualmente.

slideToggle() muestra u oculta un elemento mediante una animacion.
